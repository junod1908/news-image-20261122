Sum up 22 November 2026's world news in one image — a one-page pictorial broadsheet, "The World in One Day": painted hero panels (the Las Vegas Grand Prix under the lights, COP31 in Antalya, the ATP Finals in Turin), a dense dot world map with numbered markers, and story cards across regions and fields. Every story was date-audited to Sunday 22 November 2026 — the poster's date line says so on its face. The program copies the rendered front page (`entry.png`) to the output; the hero panels are painted illustrations composited into the page, and every word on the page is set in type by the compositing program.

> **Status: scaffold.** The front page in this commit is a draft layout; the final 19-story front page replaces `entry.png` once the research list is verified.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
